## 一、课程信息

| 项目 | 内容 |
|---|---|
| 总课时 | 96 节 |
| 章节数 | 15 章 |
| 课程定位 | 分布式消息队列 + 流式处理平台全链路（原理 → 实操 → 监控 → 集成 → 调优 → 源码） |
| 配套环境 | CentOS 7 + JDK 8 + Zookeeper + Kafka 2.4.1 + MySQL + Flume + Kafka-Eagle |
| 适合人群 | 有 Java/Linux 基础，从事大数据、后端架构、实时计算的开发者 |

## 四、学习建议路径

1. **入门路径（1-3 章）**：建立架构认知，跑通命令行收发
2. **核心原理（4-8 章）**：生产者 → Broker/副本 → 消费者，配合每日回顾巩固
3. **运维与集成（10-12 章）**：Kafka-Eagle 监控 + Flume/Flink/Spark 集成
4. **性能进阶（13 章）**：压测驱动调优，硬件→参数全链路
5. **源码深挖（14 章）**：以原理图为地图，对照源码验证每个环节
